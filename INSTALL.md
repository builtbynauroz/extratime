# Installing extratime: steps for Claude Code

The user asked you to install extratime, a terminal coding agent that runs on their own Anthropic API key. Do these steps in order. If one fails, stop and tell the user what failed and why.

1. **Check the machine.** extratime runs on macOS, Linux and Windows. `node --version` must be 20.6 or newer. If not, tell the user extratime needs Node.js 20.6+, and stop.
2. **Check for a clash.** If `command -v extratime` already finds a command, tell the user and ask before going on.
3. **Install.** `npm install -g extratime`, then check `extratime --help` prints the command list. If it fails with `EACCES` (Node from the nodejs.org installer keeps npm's global folder where only root can write), never use sudo. Run `npm config set prefix ~/.npm-global`, add `export PATH="$HOME/.npm-global/bin:$PATH"` to `~/.zshrc`, and in a new terminal run `npm install -g extratime` again. On Windows, if PowerShell won't run `extratime` because running scripts is disabled, use `extratime.cmd`.
4. **API key.** Never ask the user to paste an API key into this conversation. Tell them to get one at console.anthropic.com → API keys, then either run `extratime key add work --credit 50 --days 30` in a separate terminal window (it asks for the key without showing it), or copy the key and type `! pbpaste | extratime key add work --credit 50 --days 30` here (on Linux `wl-paste` or `xclip -selection clipboard -o` in place of `pbpaste`; in Windows PowerShell, `Get-Clipboard`). `--credit` is their budget in USD over `--days`: extratime can't see their real balance, so it meters against this.
5. **Status line, optional.** Offer to show extratime's credit in Claude Code's status line by setting `"statusLine": { "type": "command", "command": "extratime status" }` in `~/.claude/settings.json`. If a `statusLine` is already set, ask before replacing it.
6. **Hand over.** Tell the user: when Claude Code says they've hit their usage limit, run `extratime -c` in the same folder to carry on with the same conversation on their API key. `extratime --help` lists everything else. It bills their API key per token; it never uses their Claude subscription.
